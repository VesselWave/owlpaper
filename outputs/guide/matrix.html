Each pairing has treatment and control. Smoke and pilot use one training seed; research uses three. That is 40 student-training runs across all three profiles. Every seed and pairing starts from the student's own untouched reference checkpoint. A teacher dataset is generated once per profile and reused across the two student families, without changing its text.

What is saved

  • Frozen code, configurations, exact model revisions, and the complete execution plan.
  • Raw teacher strings, token IDs, sampling seeds, durations and truncation flags.
  • Every filter decision and balanced datasets with hashes.
  • Teacher and student provenance for every adapter, including cross-family source dataset hashes.
  • Token masks, every optimizer-step loss, gradient norms, memory readings, epoch adapters and optimizer-resumable checkpoints.
  • Every evaluation answer and separate plain / number-prefixed scores. Matched treatment-minus-control differences stay separate by profile, teacher, student and training seed.
  • A stage ledger, logs, live progress and an HTML report. Unfinished experiments never appear as zero transfer.

Generation and evaluation resume from flushed observations. Training resumes from the latest complete optimizer checkpoint, saved every 250 updates and after each epoch. Work beyond that checkpoint is replayed; its earlier loss log is archived. Configuration changes are rejected rather than mixed into old observations. There is one active model process at a time.

The large run can take days or longer. It is a finite sweep of the specified profiles and pairings, not an exhaustive test of all possible targets, hyperparameters or model families. Passing the smoke run is not evidence of preference transfer.

Are Qwen and OLMo genuinely separate families?

They have different pretrained checkpoints, tokenizers, architectures and training recipes. Their pretraining documents are not known to be disjoint. OLMo publishes Dolma 3, largely public-web data plus papers, code and mathematics. Qwen describes its own multilingual corpus and synthetic augmentation, but its public disclosure is insufficient for calculating document-level overlap with Dolma. Shared public-web material is plausible; the amount is unknown.

Cross-family transfer therefore tests transfer between different pretrained models. It cannot separately identify the effects of architecture, tokenizer, pretraining corpus or post-training. Similar source text does not guarantee that learned concepts occupy matching weight coordinates.
